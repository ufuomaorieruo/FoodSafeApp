# FoodSafe Compliance Dashboard

PHP + HTML + CSS + JavaScript demo application for an Azure App Service CI/CD assignment.

## Requirements
PHP 8.5 compatible. No database, Node.js, npm, Composer, or framework required.

## Local test
Run `php -S localhost:8000` in this folder and open http://localhost:8000.

## Azure
Use Azure App Service:
- Publish: Code
- Runtime: PHP 8.5
- OS: Linux

GitHub Actions uses AZURE_WEBAPP_NAME and AZURE_WEBAPP_PUBLISH_PROFILE repository secrets.
